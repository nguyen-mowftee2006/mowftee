# Mowftee

Mowftee là một AI companion local-first, ưu tiên tiếng Việt, được thiết kế cho Linux (CachyOS). Dự án tập trung vào trải nghiệm trò chuyện tự nhiên và xây dựng nhân cách (personality) riêng cho trợ lý AI.

## Trạng thái hiện tại

- **Stable Release:** `v0.1.0`
- Hỗ trợ trò chuyện văn bản qua giao diện dòng lệnh (local text chat).
- Tích hợp Ollama làm local LLM runtime.

## Hướng phát triển tương lai

- **Persona:** Xây dựng tính cách và văn phong riêng biệt.
- **Memory:** Quản lý trí nhớ hội thoại dài hạn.
- **Voice:** Hỗ trợ nhận dạng và phát âm thanh (STT/TTS).
- **Safe Linux Tools:** Tích hợp công cụ hệ thống an toàn theo allowlist.
- **Avatar:** Trực quan hóa trạng thái và biểu cảm.
